# Sanitized example configurations

These files show structure only. They are **not the user's live configuration** and cannot be applied as-is. Replace all placeholders after checking the host. Never commit real passwords, keys, private IPs, serial numbers, or account tokens.

- `fstab.example`: illustrative UUID-based mount entries.
- `mergerfs.example`: illustrative pool source and placeholder mount options.
- `snapraid.conf.example`: illustrative disk labels and content/parity paths.
- `smb.conf.example`: illustrative restricted share with placeholders.

Review distribution documentation and the installed version's man pages before adopting options. Configuration compatibility and exact option syntax must be verified for the installed packages.
